# Changelog

All notable changes to this plugin will be documented here.

## 1.0.0 (initial release)

- Added the `deskwoot` MCP server pointing at `https://deskwoot.com/api/mcp`, with OAuth sign in through Dynamic Client Registration, Client ID Metadata Documents and PKCE. It declares `placement: server`, so Grok Bot shows its connect and sign in card.
- Added the `deskwoot` rule: the order of a run, writing to customers, tickets and handling data and errors in a Deskwoot workspace.
- Added the `deskwoot-setup` skill for the agent that sets up Deskwoot and adds the live chat to a website.
- Logo: Deskwoot's mark on an indigo tile (`#3F3BE8`), as a 192 × 192 SVG and as a 192 × 192 PNG.
